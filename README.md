# 听 Tīng — learn Mandarin by listening

A small web app for learning Mandarin Chinese **by ear**, made for 5–10 minute commutes
with earphones in. No speaking, no writing — just listening and understanding.

* **Lesson mode** — hear Chinese, tap the meaning. Spaced repetition decides what comes back and when.
* **Commute mode** — hands-free audio you can play with the screen off: new words with
  English explanations, then a "what does this mean?" self-test.
* **Progress** — XP, levels, daily goal, streak, unit stars and a stats page.
* 24 topic units from greetings to everyday conversations.
